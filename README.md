# 🚌 نظام يمن باص الذكي لإدارة وتتبع الحافلات | YamenBus Smart Tracking & Management System

[![Framework](https://img.shields.io/badge/Framework-React%20Native%252BExpo-61DAFB?style=for-the-badge&logo=react)](https://reactnative.dev/)
[![Backend](https://img.shields.io/badge/Backend-PHP%20%28PDO%29-777BB4?style=for-the-badge&logo=php)](https://www.php.net/)
[![Database](https://img.shields.io/badge/Database-MySQL-4479A1?style=for-the-badge&logo=mysql)](https://www.mysql.com/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](https://opensource.org/licenses/MIT)

نظام متكامل واحترافي يهدف إلى أتمتة إدارة حافلات النقل وتتبعها بشكل مباشر جغرافيًا (Real-time GPS Tracking). يتكون النظام من لوحة تحكم إدارة ويب (Web Admin Dashboard) لمدير النظام، بالإضافة إلى تطبيقي هاتف ذكي (تطبيق للركاب وتطبيق للسائقين) تم بناؤهما باستخدام تقنيات حديثة.

---

## 🌟 ميزات النظام الرئيسية (System Features)

### 1. لوحة تحكم الويب للمسؤول (Web Admin Dashboard):
* **لوحة التحكم الرئيسية (Dashboard):** عرض إحصائيات عامة وفورية (عدد الباصات، عدد السائقين، الرحلات الجارية، الشكاوى والطلبات).
* **إدارة الحافلات وسائقين:** إدخال بيانات الحافلات، أرقام اللوحات، القدرة الاستيعابية، وإدارة ملفات السائقين ورخص القيادة.
* **إدارة الرحلات والخطوط:** رسم وإدارة مسارات الرحلات الجغرافية وتحديد سعر التذكرة ومواعيد الانطلاق والوصول.
* **التتبع المباشر (GPS Tracking Map):** عرض فوري لمواقع الحافلات النشطة على الخريطة عبر خرائط تفاعلية.
* **إدارة الحضور والانصراف والتحقق:** سجلات متكاملة ونظام طلبات تحقق للركاب والسائقين.
* **نظام التذاكر المتقدم:** حجز التذاكر وتوليد رموز الاستجابة السريعة (QR Code) الخاصة بكل تذكرة.
* **التقارير والإحصائيات:** تصدير تقارير الرحلات والمبيعات وتقييمات الركاب.
* **إعدادات النظام العامة:** تخصيص العملة، الاسم، التنبيهات، والأجهزة الذكية المتصلة.

### 2. تطبيق الركاب (Passenger App):
* عرض الرحلات المتاحة ومسارات الحافلات على خريطة تفاعلية.
* حجز التذاكر والدفع عبر المحفظة الإلكترونية (Wallet System).
* توليد بطاقة تذكرة رقمية تحتوي على **QR Code** لمسحه عند الصعود للحافلة.
* تتبع حركة الحافلة المحجوزة مباشرة على الخريطة ومعرفة الوقت المتوقع للوصول (ETA).
* نظام الشكاوى والمقترحات مع تقييم الرحلة والسائق.

### 3. تطبيق السائقين (Driver App):
* واجهة سهلة للسائق لبدء الرحلة المجدولة وإنهاؤها.
* تتبع إحداثيات GPS الخاصة بالحافلة وإرسالها بشكل دوري للخادم (Background Location Tracking).
* ماسح ضوئي لـ **QR Code** مدمج بالكامل للتحقق من تذاكر الركاب أثناء الصعود.
* عرض قائمة الركاب المحجوزين في الرحلة الحالية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

### الويب ولوحة التحكم (Web Portal):
* **اللغة الأساسية:** PHP (باستخدام PDO لضمان الحماية والاتصال الآمن بقاعدة البيانات).
* **الواجهة الأمامية:** HTML5, CSS3 (Vanilla CSS بتصميم حديث متجاوب)، JavaScript.
* **قاعدة البيانات:** MySQL (MariaDB).

### تطبيقات الهاتف (Mobile Apps):
* **المنصة الأساسية:** React Native (باستخدام Expo Framework لتسهيل التطوير والنشر).
* **إدارة التنقل:** React Navigation (Tabs, Stack).
* **الاتصال بالخادم:** Axios API Client.
* **الخرائط والتتبع:** React Native Maps & Expo Location.
* **توليد وقراءة الأكواد:** React Native SVG & Expo Camera / QR Code.

## 🚀 دليل التشغيل والتثبيت المحلي (Local Setup Guide)

### المتطلبات الأساسية (Prerequisites):
1. تثبيت برنامج **XAMPP** (لتشغيل Apache و MySQL).
2. تثبيت بيئة **Node.js** (لتشغيل تطبيقات Expo).
3. تثبيت محرر الأكواد **VS Code**.

---

### أولاً: إعداد قاعدة البيانات ولوحة الويب (XAMPP Setup)

1. **نسخ المشروع:**
   قم بنسخ مجلد المشروع بأكمله وضعه داخل مسار المشاريع في XAMPP:
   `C:\xampp\htdocs\bus`

2. **تشغيل الخوادم:**
   افتح لوحة تحكم XAMPP وقم بتشغيل خادمي **Apache** و **MySQL**.

3. **تفعيل مكتبة PDO:**
   * في لوحة XAMPP، اضغط على زر `Config` بجانب Apache واختر `PHP (php.ini)`.
   * ابحث عن السطر `;extension=pdo_mysql` وقم بإزالة الفاصلة المنقوطة `;` من بدايته.
   * ابحث عن السطر `;extension=openssl` وقم بإزالة الفاصلة المنقوطة أيضًا.
   * احفظ الملف وأعد تشغيل (Restart) خادم Apache.

4. **إنشاء قاعدة البيانات:**
   * افتح المتصفح وتوجه إلى: `http://localhost/phpmyadmin`
   * قم بإنشاء قاعدة بيانات جديدة باسم `bus_db` مع ترميز `utf8mb4_general_ci`.
   * اضغط على قاعدة البيانات `bus_db` ثم اختر التبويب `Import`.
   * قم باختيار الملف الموجود في المجلد: `database/main.sql` ثم اضغط `Go`.

5. **تعديل إعدادات الاتصال:**
   تأكد من مطابقة بيانات قاعدة البيانات في الملف:
   `src/config/database.php`
   ```php
   return [
       'host' => 'localhost',
       'dbname' => 'bus_db',
       'username' => 'root',
       'password' => '', // اتركها فارغة في XAMPP بشكل افتراضي
       'charset' => 'utf8mb4'
   ];
   ```

6. **تشغيل لوحة التحكم:**
   افتح المتصفح واذهب إلى الرابط:
   `http://localhost/bus/public/`
   سيقوم النظام بتحويلك تلقائيًا لصفحة تسجيل الدخول. (إذا كان هذا هو التشغيل الأول، سيطلب منك النظام إنشاء حساب مدير أول لمرة واحدة).

---

### ثانياً: إعداد وتشغيل تطبيقات الهاتف (Expo Mobile Apps)

اتبع هذه الخطوات لكل من مجلدي `passenger_app` و `driver_app`:

1. **تثبيت الحزم البرمجية:**
   افتح موجه الأوامر (Terminal) في مجلد التطبيق وقم بتشغيل الأمر:
   ```bash
   npm install
   ```

2. **ضبط عنوان الـ API (IP Address):**
   * بما أن التطبيق يعمل على الهاتف المحمول أو المحاكي، يجب توجيهه لعنوان الـ IP المحلي لجهاز الكمبيوتر الخاص بك وليس `localhost`.
   * ابحث عن ملف الإعدادات أو الاتصال بالـ API في كود التطبيق، وقم بتعديل الرابط ليصبح كالتالي:
     `http://<YOUR_COMPUTER_IP>/bus/public/api/`
     *(مثال: `http://192.168.1.100/bus/public/api/`)*

3. **تشغيل خادم التطوير:**
   قم بتشغيل التطبيق عبر الأمر:
   ```bash
   npm start
   ```
   * سيظهر لك كود الاستجابة السريعة (QR Code) الخاص بـ Expo في الـ Terminal.
   * قم بتحميل تطبيق **Expo Go** على هاتفك الذكي (من متجر Google Play أو Apple App Store).
   * قم بمسح الـ QR Code باستخدام التطبيق لتشغيل التطبيق على هاتفك مباشرة!

## 📦 كيفية بناء التطبيقات كملفات تثبيت APK (Building APK)

لتحويل تطبيقات الهاتف إلى ملفات تثبيت APK مستقلة تعمل بدون الحاجة لبيئة التطوير (Expo Go):

1. **تثبيت أداة EAS CLI:**
   قم بتشغيل الأمر التالي عالميًا في جهازك:
   ```bash
   npm install -g eas-cli
   ```

2. **تسجيل الدخول في Expo:**
   قم بإنشاء حساب مجاني على موقع [Expo](https://expo.dev) ثم سجل دخولك عبر الـ Terminal:
   ```bash
   eas login
   ```

3. **تهيئة إعدادات البناء (Configure Build):**
   داخل مجلد التطبيق (`passenger_app` أو `driver_app`)، قم بتشغيل الأمر:
   ```bash
   eas build:configure
   ```
   سيقوم هذا الأمر بإنشاء ملف `eas.json` في مجلد مشروعك.

4. **إعداد ملف `eas.json` للبناء المباشر للـ APK:**
   قم بفتح ملف `eas.json` والتأكد من احتوائه على إعدادات الـ `preview` لإنتاج APK مباشرة بدلاً من حزمة AAB الخاصة بالمتجر:
   ```json
   {
     "cli": {
       "version": ">= 10.0.0"
     },
     "build": {
       "development": {
         "developmentClient": true,
         "distribution": "internal"
       },
       "preview": {
         "android": {
           "buildType": "apk"
         }
       },
       "production": {}
     }
   }
   ```

5. **بدء عملية البناء (Build APK Command):**
   قم بتشغيل الأمر التالي لبدء البناء على سحابة Expo:
   ```bash
   eas build --platform android --profile preview
   ```
   * ستبدأ عملية الرفع والبناء التلقائي. عند الانتهاء، سيزودك Expo برابط مباشر لتحميل ملف الـ APK وتثبيته على أي هاتف أندرويد.
